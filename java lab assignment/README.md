## Compile and run a task

Install a Java Development Kit (JDK), then open a task folder in a terminal. For example:

```sh
cd "java lab assignment/Assignment-01/Task-01"
javac Main.java
java Main
```

Run each task from its own folder because every task uses the class name `Main`. The source file is named `Main.java` to match that public class. The included `.class` file can be recreated by compiling the source.
